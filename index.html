About the System

PLYOSTRIDE is a high-leverage application built specifically for athletes who manage high-mileage distance running alongside high-impact plyometric training. Traditional fitness trackers rely on cloud servers and superficial metrics; PLYOSTRIDE uses deterministic periodization, mathematical load management, and on-device data persistence to protect your central nervous system and tendons from chronic overload.

Core Technical Architecture

Local SQLite Database

All biometrics, workout schedules, shoe mileage logs, and readiness entries are stored strictly on your device's internal storage. Complete raw .json and .csv export capabilities guarantee absolute data ownership.

Clinical Load Management (ACWR)

Calculates your Acute:Chronic Workload Ratio to maintain training load within the optimal sweet spot (0.80–1.30), preventing spikes that lead to stress reactions and tendonitis.

Tendon & Impact Shield Protocols

Features dedicated tools for heavy isometric tendon holds, pogo cadence metronomes, post-session tendon pain check-ins (0–10), and midsole foam degradation tracking.

Deterministic 52-Week Periodization

Automates training blocks with hardcoded 4:1 mesocycle auto-deloads, 1-year race countdown tracking, and dynamic workout adjustments based on acute recovery inputs.

Installation Guide

Because PLYOSTRIDE is distributed independently to avoid external app store restrictions, follow these steps to install the APK on Android:

  1. Tap the Download APK button above to access the GitHub Releases repository.
  2. Download the latest `PLYOSTRIDE.apk` file to your Android device.
  3. Open the downloaded file. If prompted by Android security, tap Settings and enable Allow from this source.
  4. If Google Play Protect displays an unknown developer warning, tap More Details followed by Install Anyway.
